# HR Ops Platform

Production-like HR management platform deployed on AWS EKS using Terraform, ECR, RDS, S3 and Kubernetes.

---

## 🎯 Goal

This project demonstrates how to design and deploy a production-like cloud infrastructure using AWS and Kubernetes.

The focus is not only on building the system, but also on understanding and explaining the architectural decisions.

---

## 🧱 Tech Stack

- Node.js / Express
- Docker
- Amazon ECR
- Amazon EKS
- Amazon RDS (PostgreSQL)
- Amazon S3
- Terraform (Infrastructure as Code)
- Kubernetes
